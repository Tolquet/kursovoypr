# KODA.md - Инструкционный контекст проекта Global Edu Finder

## 📋 Обзор проекта

**Global Edu Finder** — это современное веб-приложение для поиска учебных заведений по всему миру. Проект представляет собой полнофункциональное React-приложение, построенное на базе Next.js, предназначенное для помощи студентам в поиске подходящих образовательных программ с интегрированной базой данных и API.

### 🎯 Основная цель
Предоставить пользователям удобный инструмент для поиска и фильтрации учебных заведений с детализированной информацией о программах, стипендиях, стоимости обучения и требованиях к поступлению.

## 🏗️ Архитектура и технологии

### Основной стек технологий
- **Frontend**: Next.js 16.0.1 с React 19.2.0
- **Язык**: TypeScript 5
- **Стилизация**: Tailwind CSS 4 + SCSS модули
- **База данных**: PostgreSQL с Prisma ORM
- **Аутентификация**: bcryptjs
- **Кэширование**: SWR для эффективного управления состоянием
- **Линтинг**: ESLint 9
- **API**: Next.js API Routes с Prisma Client

### Архитектурный подход
Проект использует **Feature-Sliced Design (FSD)** методологию с четким разделением на:
- `src/app/` - маршруты и страницы Next.js App Router
- `src/entities/` - бизнес-сущности
- `src/features/` - пользовательские сценарии (login, register)
- `src/widgets/` - крупные UI компоненты
- `src/shared/` - переиспользуемые компоненты и утилиты

### Новые возможности (последние обновления)
- **База данных**: Полная интеграция с PostgreSQL через Prisma ORM
- **API маршруты**: RESTful API для работы с данными учебных заведений
- **Сидирование**: Автоматическое заполнение базы данных тестовыми данными
- **Улучшенная фильтрация**: Расширенные категории и возможности поиска
- **Современный дизайн**: Обновленные SCSS стили с анимациями и градиентами

## 🧩 Ключевые компоненты

**Назначение**: Работа с API для получения данных учебных заведений

**Функциональность**:
- Получение данных с сервера через SWR кэширование
- Фильтрация по URL параметрам
- Создание новых записей через API
- Обработка состояний загрузки и ошибок
- Автоматическое обновление данных

**API**:
```typescript
const {
  institutes,      // Массив учебных заведений
  totalCount,      // Общее количество
  isLoading,       // Состояние загрузки
  error,           // Ошибки
  refresh,         // Обновить данные
  createInstitute  // Создать запись
} = useInstitutes(filters);
```

**Функциональность**:

- Сброс фильтров к начальному состоянию

## 🗄️ База данных

### Схема базы данных
```prisma
model Institute {
  id          Int      @id @default(autoincrement())
  name        String   @db.VarChar(255)
  description String   @db.Text
  image       String?  @db.VarChar(500)
  types       String   @db.VarChar(50)
  location    String   @db.VarChar(100)
  rating      Float    @default(0)
  tuition     String   @db.VarChar(100)
  categoryIns String[] @default([])
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

### API маршруты
- `GET /api/institutes` - Получение списка с фильтрацией
- `POST /api/institutes` - Создание нового заведения
- `GET /api/institutes/filters` - Получение доступных фильтров

### Тестовые данные
База данных предзаполнена 10 реалистичными учебными заведениями:
- МГУ, СПбПУ, ФинУниверситет, МИП, РЭУ им. Плеханова
- Московский колледж IT, Академия балета Вагановой
- Лицей "Физтех", МИФИ, ГУУ
