# Техническая документация проекта «Global Edu Finder»

---

## Введение

### Актуальность темы

В современном мире вопрос выбора образовательного учреждения становится всё более актуальным для абитуриентов, студентов и их родителей. Разнообразие университетов, колледжей, академий и школ по всему миру создаёт потребность в унифицированном инструменте поиска и сравнения учебных заведений. Традиционные методы поиска информации об образовательных учреждениях — посещение официальных сайтов, обращение к рейтинговым агентствам, консультации с профориентологами — требуют значительных временных и финансовых затрат.

В условиях глобализации образовательного пространства и развития цифровых технологий создание веб-приложения для поиска учебных заведений является своевременным и востребованным решением. Подобная платформа позволяет пользователям:

- осуществлять поиск образовательных учреждений по различным критериям (тип, категория, местоположение, рейтинг, стоимость обучения);
- получать детализированную информацию о программах и требованиях к поступлению;
- проходить профориентационные тесты для определения наиболее подходящего направления обучения;
- сохранять результаты исследований и тестирования в личном кабинете.

Развитие технологий веб-разработки, таких как серверный рендеринг (SSR), статическая генерация (SSG), прогрессивные веб-приложения (PWA), открывает новые возможности для создания высокопроизводительных и доступных решений в сфере образования.

### Цели и задачи проекта

**Целью** данного проекта является разработка полнофункционального веб-приложения «Global Edu Finder» для поиска и фильтрации учебных заведений по всему миру с интегрированной системой аутентификации и профориентационного тестирования.

**Задачи проекта:**

1. **Анализ требований и проектирование архитектуры:**
   - сбор и формализация функциональных и нефункциональных требований;
   - определение ключевых сущностей и их взаимосвязей;
   - проектирование архитектуры приложения;
   - разработка прототипа интерфейса.

2. **Реализация системы авторизации и регистрации:**
   - создание форм регистрации и входа с валидацией данных;
   - хеширование паролей с использованием bcrypt;
   - управление сессиями через JWT-токены;
   - разграничение прав доступа;
   - защита от распространённых атак (CSRF, XSS).

3. **Реализация поиска и фильтрации учебных заведений:**
   - разработка универсальной системы фильтрации;
   - интеграция с базой данных через Prisma ORM;
   - оптимизация запросов с использованием кэширования (SWR);
   - синхронизация состояния фильтров с URL-параметрами.

4. **Взаимодействие с базой данных:**
   - проектирование моделей Prisma ORM;
   - создание и применение миграций;
   - оптимизация запросов к базе данных;
   - реализация транзакций и обработка ошибок.

5. **Интеграция API:**
   - разработка RESTful API эндпоинтов;
   - документирование API;
   - обработка ошибок и валидация входных данных.

6. **Реализация профориентационных тестов:**
   - разработка системы тестирования (MBTI, Холланд, оценка навыков);
   - сохранение результатов в базе данных;
   - отображение статистики и прогресса.

7. **Тестирование:**
   - юнит-тесты для компонентов и хуков;
   - проверка качества кода (ESLint);
   - логирование действий пользователя.

8. **Развёртывание на сервере:**
   - подготовка к продакшен-развёртыванию;
   - конфигурация окружения.

#### Использование объектно-ориентированного программирования

В проекте используются принципы ООП на уровне TypeScript:

```typescript
// Пример: Типизация с использованием интерфейсов
interface Institute {
  id: number;
  name: string;
  description: string;
  types: string;
  location: string;
  rating: number;
  tuition: string;
  categoryIns: string[];
}

// Пример: Класс-хук с инкапсуляцией логики
class useInstitutes {
  private fetcher: Fetcher;
  private baseUrl: string;
  
  constructor() {
    this.baseUrl = '/api/institutes';
    this.fetcher = fetcher;
  }
  
  getInstitutes(params: FilterParams): SWRResponse {
    return useSWR(this.buildUrl(params), this.fetcher);
  }
}
```

#### API-эндпоинты

| Метод | Путь | Описание | Параметры |
|-------|------|----------|-----------|
| GET | `/api/institutes` | Получение списка учебных заведений | `type`, `category`, `search` |
| POST | `/api/institutes` | Создание нового заведения | Body: Institute |
| GET | `/api/institutes/filters` | Получение доступных фильтров | - |
| POST | `/api/auth/register` | Регистрация нового пользователя | `email`, `name`, `password` |
| POST | `/api/auth/[...nextauth]` | Аутентификация (вход/сессия) | `email`, `password` |
| GET | `/api/auth/session` | Получение текущей сессии | - |

## 2. Реализация системы авторизации и регистрации

### 2.1. Создание форм регистрации и входа

#### Архитектура аутентификации

Система аутентификации построена на базе **NextAuth.js** с использованием провайдера учётных данных (Credentials Provider). Данное решение обеспечивает:

- Гибкую настройку стратегии аутентификации
- Интеграцию с JWT-токенами
- Управление сессиями на сервере
- Защищённое хеширование паролей

#### Валидация данных

```typescript
// src/app/api/auth/register/route.ts
import { NextRequest, NextResponse } from 'next/server';
import bcrypt from 'bcryptjs';
import prisma from '@/lib/prisma';

export async function POST(request: NextRequest) {
  try {
    const { email, name, password } = await request.json();

    // Валидация email
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    if (!emailRegex.test(email)) {
      return NextResponse.json(
        { error: 'Некорректный формат email' },
        { status: 400 }
      );
    }

    // Валидация пароля (минимум 8 символов)
    if (password.length < 8) {
      return NextResponse.json(
        { error: 'Пароль должен содержать минимум 8 символов' },
        { status: 400 }
      );
    }

    // Проверка существования пользователя
    const existingUser = await prisma.user.findUnique({
      where: { email },
    });

    if (existingUser) {
      return NextResponse.json(
        { error: 'Пользователь с таким email уже существует' },
        { status: 409 }
      );
    }

    // Хеширование пароля
    const hashedPassword = await bcrypt.hash(password, 12);

    // Создание пользователя
    const user = await prisma.user.create({
      data: {
        email,
        name,
        password: hashedPassword,
      },
    });

    return NextResponse.json(
      { message: 'Пользователь успешно зарегистрирован', userId: user.id },
      { status: 201 }
    );
  } catch (error) {
    return NextResponse.json(
      { error: 'Ошибка при регистрации пользователя' },
      { status: 500 }
    );
  }
}
```

### 2.2. Управление сессиями и cookies

#### Конфигурация NextAuth

```typescript
// src/app/api/auth/[...nextauth]/route.ts
import NextAuth, { NextAuthOptions } from 'next-auth';
import CredentialsProvider from 'next-auth/providers/credentials';
import bcrypt from 'bcryptjs';
import prisma from '@/lib/prisma';

export const authOptions: NextAuthOptions = {
  providers: [
    CredentialsProvider({
      name: 'Credentials',
      credentials: {
        email: { label: 'Email', type: 'email' },
        password: { label: 'Password', type: 'password' },
      },
      async authorize(credentials) {
        if (!credentials?.email || !credentials?.password) {
          return null;
        }

        const user = await prisma.user.findUnique({
          where: { email: credentials.email },
        });

        if (!user) {
          return null;
        }

        const isValid = await bcrypt.compare(
          credentials.password,
          user.password
        );

        if (!isValid) {
          return null;
        }

        return {
          id: user.id.toString(),
          email: user.email,
          name: user.name,
        };
      },
    }),
  ],
  session: {
    strategy: 'jwt',
    maxAge: 30 * 24 * 60 * 60, // 30 дней
  },
  callbacks: {
    async jwt({ token, user }) {
      if (user) {
        token.id = user.id;
      }
      return token;
    },
    async session({ session, token }) {
      if (session.user) {
        session.user.id = token.id as string;
      }
      return session;
    },
  },
  pages: {
    signIn: '/login',
    error: '/login',
  },
};

const handler = NextAuth(authOptions);
export { handler as GET, handler as POST };
```

### 2.4. Защита от атак

#### Защита от CSRF (Cross-Site Request Forgery)

NextAuth.js автоматически обеспечивает защиту от CSRF-атак благодаря использованию CSRF-токенов для всех POST-запросов ( состояний ), которые подписываются секретом приложения.

#### Защита от XSS (Cross-Site Scripting)

- **Экранирование вывода**: React автоматически экранирует данные, предотвращая внедрение скриптов
- **Content Security Policy**: Next.js обеспечивает базовую защиту заголовками
- **Валидация ввода**: Все данные валидируются на сервере перед обработкой
- **bcrypt**: Пароли хешируются, что предотвращает утечку даже при компрометации БД

#### useUniversalFilter Hook

```typescript
// src/hooks/useUniversalFilter.tsx
'use client';

import { useMemo, useState, useCallback } from 'react';

interface FilterState {
  search: string;
  types: string[];
  categories: string[];
}

export function useUniversalFilter(initialFilters: FilterState) {
  const [filters, setFilters] = useState<FilterState>(initialFilters);

  const updateSearch = useCallback((search: string) => {
    setFilters((prev) => ({ ...prev, search }));
  }, []);

  const updateTypes = useCallback((types: string[]) => {
    setFilters((prev) => ({ ...prev, types }));
  }, []);

  const updateCategories = useCallback((categories: string[]) => {
    setFilters((prev) => ({ ...prev, categories }));
  }, []);

  const resetFilters = useCallback(() => {
    setFilters(initialFilters);
  }, [initialFilters]);

  const filteredData = useMemo(() => {
    return (data: Institute[]): Institute[] => {
      return data.filter((item) => {
        // Фильтрация по поисковому запросу
        if (filters.search) {
          const searchLower = filters.search.toLowerCase();
          const matchesSearch =
            item.name.toLowerCase().includes(searchLower) ||
            item.description.toLowerCase().includes(searchLower) ||
            item.location.toLowerCase().includes(searchLower);
          if (!matchesSearch) return false;
        }

        // Фильтрация по типам
        if (filters.types.length > 0) {
          if (!filters.types.includes(item.types)) return false;
        }

        // Фильтрация по категориям
        if (filters.categories.length > 0) {
          const hasCategory = filters.categories.some((cat) =>
            item.categoryIns.includes(cat)
          );
          if (!hasCategory) return false;
        }

        return true;
      });
    };
  }, [filters]);

  return {
    filters,
    updateSearch,
    updateTypes,
    updateCategories,
    resetFilters,
    filteredData,
  };
}
```

        { description: { contains: search, mode: 'insensitive' } },
        { location: { contains: search, mode: 'insensitive' } },
      ];
    }

    const institutes = await prisma.institute.findMany({
      where,
      orderBy: {
        rating: 'desc',
      },

    return NextResponse.json(

          type: searchParams.get('type') || 'all',

// Универсальный обработчик ошибок API
export async function GET(request: NextRequest) {
  try {
    // Логика обработки запроса
    const data = await processRequest(request);
    return NextResponse.json(data);
  } catch (error) {
    console.error('API Error:', error);
    
    return NextResponse.json(
      { 
        error: 'Внутренняя ошибка сервера',
        code: 'INTERNAL_ERROR',
        timestamp: new Date().toISOString(),
      },
      { status: 500 }
    );
  }
}

// Валидация входных данных
function validateInstituteInput(data: any): ValidationResult {
  const errors: string[] = [];
  
  if (!data.name || data.name.length < 2) {
    errors.push('Название должно содержать минимум 2 символа');
  }
  
  if (!data.types || !['university', 'college', 'school', 'institute', 'academy'].includes(data.types)) {
    errors.push('Некорректный тип учебного заведения');
  }
  
  return {
    valid: errors.length === 0,
    errors,
  };
}
